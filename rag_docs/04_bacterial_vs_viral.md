# Bacterial and viral pneumonia on X-rays
Source: https://doi.org/10.1016/j.cell.2018.02.010

The dataset used for this project labels pneumonia X-rays as bacterial or viral, but this app only predicts NORMAL or PNEUMONIA. In the original study, bacterial pneumonia typically showed a focal consolidation in one lobe, while viral pneumonia showed a more diffuse, interstitial pattern in both lungs.

These patterns overlap a lot, so an X-ray alone cannot reliably tell bacterial from viral pneumonia. Doctors use symptoms, examination and tests to decide on the cause and the treatment.
